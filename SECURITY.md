# Security policy

Nib-E opens files from strangers (PDFs can carry scripts, links and attachments),
so security reports are very welcome.

## Report a problem privately

Please **do not open a public issue** for a security problem.
Use GitHub's private reporting instead: **Security → Report a vulnerability** on this
repository's page. Include the steps to reproduce it and, if possible, a small PDF
that shows it (never a document with real personal data).

You get an answer within 7 days. Fixes are released as soon as they are ready and
credited in the changelog if you like.

## What counts

- A PDF that makes Nib-E run code, open links, files or programs, or reach the network
- Redaction that leaves removed text or picture content recoverable
- The desktop app reading or writing files the person did not choose
- Saved files that are damaged, or contain data the person removed

## Supported versions

Only the latest release gets fixes. Nib-E never updates itself: update by installing
the newest version from the Releases page.
