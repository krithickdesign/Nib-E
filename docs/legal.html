1. Verantwortlicher

Verantwortlich für die Datenverarbeitung auf dieser Website ist die im Impressum genannte Person.

2. Die App Nib-E verarbeitet Ihre Dateien nur auf Ihrem Gerät

Nib-E (Web-Version und Desktop-App) öffnet, bearbeitet und speichert PDF-Dateien ausschließlich auf Ihrem Gerät. Es werden keine Dateien, Dateiinhalte oder Nutzungsdaten an uns oder Dritte übertragen. Die Web-Version ist durch Sicherheitsregeln (Content Security Policy) daran gehindert, nach dem Laden Verbindungen aufzubauen; die Desktop-App hat keine Internet-Berechtigung.

Lokal im Browser bzw. in der App gespeichert werden nur: Einstellungen, eine von Ihnen gespeicherte Unterschrift, eigene Stempel, Lernnotizen, Kopien ungespeicherter Arbeit (Wiederherstellung nach Absturz) und die vorherige Version überschriebener Dateien. Diese Daten verlassen Ihr Gerät nicht und können unter „Toolbox → Settings → Forget everything“ gelöscht werden.

Es werden keine Cookies, keine Analyse- oder Tracking-Werkzeuge und keine KI-Dienste verwendet.

Eine Übermittlung in die USA erfolgt auf Grundlage des EU-US Data Privacy Framework. Weitere Informationen: GitHub Privacy Statement.
