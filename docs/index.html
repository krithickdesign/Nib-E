Private by design

And your PDFs never leave your computer.

Most online PDF tools upload your documents to their servers. Nib-E does all the work inside your browser, so contracts, IDs and exam papers stay with you.

Network: none

Opening, editing and saving happen on your device. The desktop app has no internet permission at all, and the web version can only load its own text-recognition files from this site once loaded.

No account, no tracking, no AI

Nothing about you or your files is collected. No AI service ever sees your text.

Safe mode

Scripts inside PDFs never run and links can't open anything by themselves. Nib-E shows what it blocked.

Desktop app

Install Nib-E. It never goes online.

Same Nib-E, as a normal app: opens PDFs from your file manager (“Open with Nib-E”), saves straight back to the file, and has no permission to use the internet. Free, no account.

Before you download for macOS

File: Nib-E_…_universal.dmg (Apple silicon and Intel), from the latest release on GitHub.

First start: macOS says Nib-E cannot be opened, because it is not notarised by Apple yet. Open System Settings → Privacy & Security, scroll down, click Open Anyway. You only do this once.

No install needed? Open Nib-E in your browser: same features, works offline once loaded.

Before you download for Linux

We recommend the web version on Linux: open Nib-E in your browser. Same features, works offline once loaded, nothing to install.

Prefer an app?

Take the .deb (Ubuntu, Debian, Mint) from the latest release on GitHub and double-click it to install with your software centre. The .AppImage works on any distribution: make it executable (right-click → Properties → Allow executing), then double-click it.

Blank window or crash at start? Start it once more: Nib-E then switches to software drawing by itself. You can also start it with NIB_SAFE_GRAPHICS=1.
